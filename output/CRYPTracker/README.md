# CRYPTracker - Real-Time Crypto Price Tracker

Built autonomously by **GravityDesk** Engineering Swarm.

## Features
- **Live WebSocket Ticker**: High-frequency streaming for BTC, ETH, SOL, BNB, XRP with auto-reconnection.
- **Microsecond Animation Throttle**: Batched price state updates preventing UI frame drops.
- **Interactive Price Charting**: 24h high/low, volume, and simulated sparklines.
- **Price Alert Engine**: Set price alerts with visual toasts when limits trigger.
- **Order Book & Depth Ladder**: Live bids and asks streaming.
- **Responsive Glassmorphism UI**: Dark mode dashboard built with Tailwind CSS.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Run tests:
```bash
npm run test
```
